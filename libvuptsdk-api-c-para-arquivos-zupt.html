libvuptsdk: API C para arquivos ZUPT

SDK em C para criar, verificar e extrair arquivos ZUPT a partir de outras aplicações.

Acessar projeto ↗

Conteúdo

libvuptsdk é o SDK que desenvolvo para aplicações que precisam criar, verificar e extrair arquivos ZUPT por uma API C. A distribuição de código-fonte 2.1.0-base.1 integra o motor do ZUPT 5.2.9 e o codec VaptVupt 2.65.11, com bibliotecas estática e compartilhada, cabeçalho público, exemplos e pkg-config.

Imagem: captura da documentação no repositório da libvuptsdk; o SDK não tem interface gráfica própria.

O SDK tem um propósito diferente do arquivador ZUPT e do codec independente: expor operações de arquivo a programas de terceiros. A API de base é uma prévia e não equivale ao antigo binário de ABI completa, que inclui funções extras sem fonte integral neste repositório. O guia recomenda limites de extração por contexto; a API de I/O por callback ainda usa arquivos temporários e não é streaming de memória constante.
