Automation with SSH for Hacking

First steps:

Debian: | apt update && apt upgrade && apt install sshpass pssh torsocks -y Fedora: dnf update && dnf upgrade && dnf install sshpass pssh tor torsocks -y Gentoo: emerge sshpass pssh tor torsocks

START TOR!

SYSTEMD USERS
systemctl enable tor
systemctl start tor
OPENRC USERS
rc-service tor enable
rc-service tor start

Are you prepared? OK... start with this:

      torify sshpass -p "segfault" pssh -A -i -H "root@lsd.segfault.net:22" uname -a
