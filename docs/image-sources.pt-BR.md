# Fontes das imagens de projetos

[English](image-sources.md)

As imagens WebP em `images/projects/` são cópias otimizadas para carregamento rápido. As capturas da wiki documentam o estado dos serviços em 7 de setembro de 2026; elas não representam uma versão atual em tempo real. Os artigos vinculam a página ou o repositório de origem de cada imagem. A tabela canônica de arquivos e fontes está em [Project image sources](image-sources.md).
